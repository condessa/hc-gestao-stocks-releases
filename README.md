# HC-Gestão Stocks — atualizações

Repositório público usado pela aplicação para verificar e descarregar novas versões.

- `versao.json` — versão mais recente, notas, endereço e `sha256` de cada instalador.
- Os instaladores ficam anexados às **releases** desta página.

O código-fonte não está aqui. O programa lê este ficheiro ao arrancar (pode ser desligado nas
Definições) e só instala depois de confirmar o `sha256`.
